# Telegram Бот-Рандомайзер

Простой Telegram-бот для случайного выбора вариантов, подбрасывания монетки, броска кубика и разделения на команды.

## Требования

- Python 3.11+
- aiogram 3.x
- python-dotenv

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корне проекта и добавьте токен бота:
   ```
   BOT_TOKEN=ваш_токен_здесь
   ```
   
   Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram.

## Запуск

Запустите бота командой:
```bash
python app.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота и показать меню |
| `/choose` | Выбрать случайный вариант из списка |
| `/yesno` | Получить ответ Да/Нет на вопрос |
| `/coin` | Подбросить монетку (Орёл/Решка) |
| `/dice` | Бросить кубик (1-6) |
| `/teams` | Разделить участников на 2 команды |
| `/help` | Показать инструкцию |

## Примеры использования

### Выбор из списка
```
пицца, суши, бургер
```
или
```
фильм 1 / фильм 2 / фильм 3
```
или
```
вариант 1
вариант 2
вариант 3
```

### Разделение на команды
```
Анна, Борис, Виктор, Дарья
```
или
```
Игрок 1
Игрок 2
Игрок 3
Игрок 4
```
