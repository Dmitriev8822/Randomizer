# Telegram Бот "Случайное число"

Простой телеграм-бот, который генерирует случайные числа от 1 до 100.

## Описание

Бот предоставляет пользователю возможность получить случайное число нажатием на кнопку. При запуске бот приветствует пользователя и предлагает нажать кнопку для генерации числа.

## Требования

- Python 3.x
- Библиотека `pyTelegramBotAPI` (telebot)

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram.

4. Замените `YOUR_BOT_TOKEN_HERE` в файле `app.py` на ваш токен:
   ```python
   BOT_TOKEN = 'ваш_токен_здесь'
   ```

## Запуск

Запустите бота командой:
```bash
python app.py
```

## Использование

1. Откройте диалог с вашим ботом в Telegram.
2. Отправьте команду `/start`.
3. Нажмите на кнопку **"🎲 Получить случайное число"**.
4. Бот ответит случайным числом от 1 до 100.
