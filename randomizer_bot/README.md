# Telegram Bot Randomizer

Простой Telegram-бот для рандомизации без ИИ, баз данных и внешних API.

## Возможности

- **Выбрать из списка** — случайный выбор одного варианта из вашего списка
- **Да / Нет** — ответ на вопрос (Да, Нет, Скорее да, Скорее нет, Позже, Не сегодня)
- **Монетка** — подбрасывание монетки (Орёл/Решка)
- **Кубик** — бросок кубика (1-6)
- **Команды** — разделение участников на 2 команды

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Получите токен бота:
   - Откройте @BotFather в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям
   - Скопируйте полученный токен

4. Создайте файл `.env` в папке проекта:
```bash
cp .env.example .env
```

5. Вставьте токен в файл `.env`:
```
BOT_TOKEN=ваш_токен_от_botfather
```

## Запуск

```bash
python app.py
```

## Использование

Отправьте боту `/start` для начала работы.

### Команды

- `/start` — запустить бота и показать меню
- `/help` — показать справку
- `/choose` — выбрать случайный вариант из списка
- `/yesno` — получить ответ Да/Нет
- `/coin` — подбросить монетку
- `/dice` — бросить кубик
- `/teams` — разделить на команды

### Форматы ввода

**Для /choose:**
- Через запятую: `пицца, суши, бургер`
- Через слэш: `фильм 1 / фильм 2 / фильм 3`
- Через перенос строки:
  ```
  вариант 1
  вариант 2
  вариант 3
  ```

**Для /teams:**
- Через запятую: `Анна, Борис, Виктор, Дарья`
- Через перенос строки:
  ```
  Анна
  Борис
  Виктор
  Дарья
  ```
